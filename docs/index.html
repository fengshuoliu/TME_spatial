TME Spatial

A Streamlit app for multi-channel overlay generation, nuclei segmentation, interactive cell-type definition, region boundary analysis, and distance-based spatial quantification from ImageJ-exported .csv/.txt intensity grids.

  • Upload-only web workflow that stays close to the original notebook logic
  • End-to-end outputs saved as figures, masks, CSV tables, and JSON configs
  • Designed for local use, lab sharing, and GitHub Pages project documentation

Overview

What this project does

Input

ImageJ-exported text images saved as rectangular numeric grids, typically one file per marker channel.

Core analysis

Channel overlays, nuclei segmentation, rule-based cell typing, region masks, nearest-neighbor distances, and cell-to-boundary distances.

Outputs

SVG/TIFF figures, uint8/uint16 masks, CSV summaries, per-step JSON parameter files, and ZIP download from the app.

Workflow

How to use the app

The figures below map directly onto the tabs in the Streamlit interface and show the expected order of operations.

1

Export each channel from Fiji / ImageJ as a text image

Save each marker as a rectangular numeric text grid. The app accepts .csv and .txt files and auto-detects common delimiters.

2

Upload files and configure channels

Choose channel files, marker names, colors, pixel calibration, and overlay settings before saving the configuration.

3

Preview the overlay

Generate the composite view and split-channel panels to confirm channel mapping and signal quality.

4

Run nuclei segmentation

Select the nuclear channel, tune segmentation parameters, and save masks and segmentation figures.

5

Define cell types

Build rule-based cell types with positive and negative marker logic or advanced boolean expressions.

6

Assign cell types and build masks

Apply the saved rules to segmented nuclei and generate cell-level tables, marker masks, and cell-type figures.

7

Compute region boundaries

Use one or more cell types to define a region, then refine it with closing, dilation, and filtering parameters.

8

Run distance analyses

Compare query cell types using nearest-neighbor distances or distances to saved boundaries.

9

Download all outputs as a ZIP

The app lists generated files and packages the session outputs for export. This includes figures, TIFF masks, CSV tables, and JSON parameter files.

Install

Run the app locally

macOS / Linux

python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python -m streamlit run app.py

Windows PowerShell

py -3.11 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m streamlit run app.py

The repository README contains the full installation notes, including the Windows-specific instructions.

Publish

Use this folder as a GitHub Pages project site

What to upload

Commit the entire docs/ folder, including index.html, CSS, images, and videos, to the repository.

  • docs/index.html
  • docs/assets/site.css
  • docs/assets/images/*
  • docs/assets/videos/*
  • docs/.nojekyll

Recommended GitHub Pages setup

Publish from the main branch and the /docs folder. After pushing these files, enable GitHub Pages in repository settings and point it to main / docs.

Your site URL will look like:
https://<username>.github.io/TME_spatial/

Tip

Keep the project website in docs/ and the Streamlit application in the repository root. This cleanly separates the static documentation site from the runnable app code.
